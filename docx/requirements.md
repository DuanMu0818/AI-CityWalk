# 功能需求规格书

## 1. 项目概述

### 1.1 项目定位
AI CityWalk 是一个面向年轻用户的智能城市漫步路线规划 Web 应用。用户通过自然语言 + 表单选择描述旅行偏好，AI 自动生成一条主题鲜明、空间合理的 CityWalk 路线，并在地图上可视化展示。

### 1.2 目标用户
- 喜欢城市探索的年轻人
- 自由旅行者
- 周末想找新鲜路线散步的城市居民
- 对编程不熟悉的普通用户（界面要友好直观）

---

## 2. 功能需求

### 2.1 用户输入（表单 + 文本框混合）

#### 2.1.1 城市选择
- **输入方式**：文本输入框
- **范围**：支持全国任意城市
- **验证**：必填项，不能为空

#### 2.1.2 主题风格
- **输入方式**：胶囊标签按钮（单选）
- **预设选项**：
  - 文艺范
  - 美食之旅
  - 历史探秘
  - 复古怀旧
  - 自然风光
  - 潮流打卡
- **验证**：可选项，不选则由 AI 自由发挥

#### 2.1.3 时间/体力偏好
- **输入方式**：选择器（单选）
- **预设选项**：
  - 半天轻松逛（3-4 个途经点）
  - 一整天深度游（6-8 个途经点）
  - 暴走模式（8-10 个途经点）
- **验证**：可选项，默认由 AI 智能决定

#### 2.1.4 预算偏好
- **输入方式**：选择器（单选）
- **预设选项**：
  - 学生党平价
  - 轻奢体验
  - 不设预算
- **验证**：可选项

#### 2.1.5 特殊需求
- **输入方式**：多选标签按钮
- **预设选项**：
  - 适合拍照
  - 有咖啡馆休息
  - 带小孩友好
  - 无障碍友好
- **验证**：可选项，可多选

#### 2.1.6 自由描述
- **输入方式**：多行文本框
- **说明**：用户自由补充偏好，如"想吃川菜、喜欢老建筑、不想去太商业化的地方"
- **验证**：可选项

### 2.2 路线生成

#### 2.2.1 AI 生成逻辑
- 由 DeepSeek 大语言模型根据用户偏好生成路线
- AI 只返回地点名称和描述信息，不返回坐标
- 后端通过腾讯地理编码 API 将地点名转换为 GCJ-02 坐标
- 途经点数量由 AI 根据时间偏好智能决定

#### 2.2.2 路线数据结构
每条路线包含：
- `route_name`：路线名称（有创意和主题感）
- `theme`：主题标签
- `city`：城市名
- `summary`：一句话路线概述
- `waypoints`：途经点数组

#### 2.2.3 途经点信息
每个途经点包含：
- `name`：地点全称（如"宽窄巷子"）
- `category`：类型（如"历史街区/美食/公园/博物馆/咖啡馆"）
- `description`：2-3 句推荐理由
- `stay_minutes`：建议停留时间（分钟）
- `tips`：实用小贴士（最佳到达时间、拍照角度、必吃推荐等）
- `lat`：纬度（GCJ-02，由腾讯地理编码返回）
- `lng`：经度（GCJ-02，由腾讯地理编码返回）

### 2.3 地图展示

#### 2.3.1 地图功能
- 使用腾讯地图 JS API GL
- 支持缩放、拖拽
- 路线生成后自动调整视野（fitBounds）覆盖所有途经点

#### 2.3.2 标记点
- 使用自定义图标（圆形背景 + 白色编号）
- 默认颜色：主色 `#4A90D9`
- 高亮颜色：暖橙 `#E6A23C` + 放大效果
- 点击标记弹出信息窗口（显示地点名称 + 类别 + 简介）

#### 2.3.3 路线连线
- 用折线连接各途经点
- 颜色 `#4A90D9`，宽度 4px，透明度 0.7
- 可选虚线样式增加设计感

#### 2.3.4 交互
- 点击下方路线详情卡片时，对应地图标记高亮
- 点击地图标记时，对应详情卡片滚动到视野中

### 2.4 等待动画

#### 2.4.1 触发时机
- 用户点击"生成路线"按钮后立即显示
- AI 返回结果后自动隐藏

#### 2.4.2 动画效果（5 层）
1. 全屏毛玻璃遮罩（`backdrop-filter: blur(8px)`）
2. 步行小人弹跳动画（CSS 实现）
3. 路径虚线从左到右延伸动画
4. 主色脉冲光环扩散动画
5. 5 个进度点依次亮起循环

#### 2.4.3 轮换文字（每 3 秒切换）
- "🧭 AI 正在为你探索路线..."
- "🏙️ 正在搜索 {城市} 的好去处..."
- "🚶 规划最佳步行路线中..."
- "📍 正在标记精彩地点..."
- "✨ 即将完成，请稍候..."

#### 2.4.4 退出动画
- 遮罩以 opacity + scale 渐隐退出（0.3s）
- 路线内容渐显入场

### 2.5 历史记录

#### 2.5.1 存储
- 使用 SQLite 数据库存储
- 每次生成路线自动保存

#### 2.5.2 查看
- 侧滑抽屉面板展示历史路线列表
- 每条显示：城市 + 主题 + 路线名称 + 日期

#### 2.5.3 回看
- 点击历史路线 → 重新加载到地图 + 显示详情卡片
- 支持删除历史路线（需确认弹窗）

## 3. 非功能需求

### 3.1 响应式设计
- 桌面端（>768px）：左右分栏（表单 | 地图）
- 移动端（≤768px）：上下排列（表单在上，地图在下）
- 适配范围：375px ~ 1440px

### 3.2 性能
- AI 生成超时设置 60 秒
- 前端 API 请求超时 60 秒
- 地理编码失败时优雅降级（跳过该点）

### 3.3 错误处理
- 网络错误：友好提示"网络连接失败，请检查网络后重试"
- AI 超时：提示"AI 正在思考中，请稍后再试"
- 生成失败：提示"路线生成失败，请换个描述试试"
- 表单验证：至少填写城市

### 3.4 跨域
- 后端配置 CORS，允许前端 localhost 调用后端 API
- 前端通过 Live Server 或文件方式打开（不同端口）
